2Frontend và Backend là gì?

Một website gồm hai phần: phần em nhìn thấy và phần chạy phía sau.

Frontend – Mặt tiền

Phần người dùng nhìn thấy và tương tác: nút bấm, ô nhập, màu sắc.

Công nghệ: HTML, CSS, JavaScript

Backend – Hậu trường

Phần xử lý dữ liệu trên máy chủ: nhận, tính toán, lưu trữ.

Công nghệ: Python + Flask

3Server hoạt động như thế nào?

Server (máy chủ) là máy tính luôn bật, chờ người khác nhờ việc rồi trả kết quả.

🌐Trình duyệtChrome, Edge…
RequestResponse
🖥️ServerChạy Flask
① Request (yêu cầu): trình duyệt nhờ server làm một việc.
② Server nhận và xử lý yêu cầu.
③ Response (phản hồi): server trả kết quả về.
④ Trình duyệt hiển thị kết quả cho người dùng.
📚 Ví dụ: Em là trình duyệt, thủ thư là server. Em hỏi mượn sách (Request) → thủ thư đưa sách (Response).

4URL, HTTP và mã trạng thái

HTTP (HyperText Transfer Protocol) là bộ quy tắc chung để trình duyệt (client – bên xin việc) và server hiểu nhau.

http://Giao thức: dùng HTTP để nói chuyện
127.0.0.1Host: địa chỉ máy chủ. Đây là chính máy em (localhost)
:5000Port: “cửa” của chương trình; Flask mặc định dùng 5000
/sendPath (route): việc hoặc trang cần truy cập
Request gồm:
① Method (GET, POST) ② URL
③ Headers: thông tin kèm theo ④ Body: dữ liệu gửi đi (thường ở POST)
Response gồm:
① Status code: mã kết quả ② Headers
③ Body: nội dung trả về (HTML hoặc JSON)

Status code (mã trạng thái) cho biết Request thành công hay lỗi:

200 OKThành công
404 Not FoundSai route, không tìm thấy
405 Method Not AllowedSai phương thức
500 Server ErrorCode Python bị lỗi

4Làm quen với Flask

Flask là thư viện Python nhỏ gọn để tạo web server – ít code, dễ học, chạy ngay.

Cài đặt và chạy
pip install flask
python app.py
Mở trình duyệt: http://127.0.0.1:5000
from flask import Flask app = Flask(__name__) @app.route("/")def home():    return "Hello World!" app.run(debug=True)
  • 1 Nhập (import) công cụ Flask vào chương trình.
  • 2 Tạo app – chính là server của em.
  • 3 Route (đường dẫn): địa chỉ URL. “/” là trang chủ. Dấu @ (decorator) gắn route vào hàm ngay bên dưới.
  • 4 Hàm chạy khi có người truy cập route; return là Response gửi về.
  • 5 Bật server. debug=True tự tải lại khi em sửa code.

6JSON và fetch(): ngôn ngữ chung của JavaScript và Python

Hai ngôn ngữ khác nhau cần một định dạng chung để trao đổi dữ liệu.

JSON (JavaScript Object Notation): văn bản ghi dữ liệu dạng khóa: giá trị.
Khóa và chuỗi đặt trong dấu nháy kép, các cặp cách nhau bằng dấu phẩy.
{  "name": "Lan",  "age": 13}
Gửi đi (POST):
object JavaScript → JSON.stringify() → chuỗi JSON → request.get_json() → dict Python
Trả về (Response):
dict Python → jsonify() → chuỗi JSON → res.json() → object JavaScript
fetch() gửi Request và trả về một Promise – “lời hứa” rằng kết quả sẽ có sau, vì server cần thời gian trả lời.
await = đợi server trả lời xong rồi mới chạy tiếp. async đánh dấu hàm có dùng await.
🍕 Như đặt pizza: đợi shipper tới rồi mới ăn.

6GET và POST

Hai phương thức (method) để gửi Request. Chọn đúng việc cần làm.

POST – Gửi dữ liệu đến server · như bỏ thư vào hộp thư 📮
Người dùnggửi tên “Lan”
POST name="Lan"
Server nhận tên
name = trống"Lan"
GET – Lấy dữ liệu từ server · như mở hộp thư xem thư 📬
Người dùngmuốn xem tên
GET /get“Lan”
Server trả tên đã lưu
name = "Lan"

Nhớ nhanh: POST = đưa đi (dữ liệu đi từ HTML đến Flask), GET = lấy về (dữ liệu quay về HTML).

7So sánh GET và POST

Chọn phương thức theo mục đích của Request.

GETPOST
Mục đíchLấy dữ liệu từ serverGửi dữ liệu đến server
Dữ liệu nằm ởTrên URL, ví dụ /get?name=LanTrong Body của Request
Thay đổi server?Không, chỉ đọcCó: lưu, tạo hoặc sửa dữ liệu
Độ riêng tưDữ liệu hiện trên URL, không dùng cho mật khẩuKhông hiện trên URL (vẫn cần HTTPS để an toàn)
Kích thướcNhỏ, URL có giới hạn độ dàiLớn hơn nhiều
Trong FlaskMặc định: @app.route("/get")Phải khai báo: methods=["POST"]
Ví dụ đời thườngMở hộp thư xem thư, tìm kiếmBỏ thư vào hộp, đăng nhập, gửi biểu mẫu
💡 Gõ địa chỉ vào thanh trình duyệt luôn gửi GET. Nếu gửi GET đến route chỉ cho phép POST, server trả lỗi 405.

12Bước 3a – Viết app.py: giải thích từng dòng

File Python, toàn bộ phần Backend. Dòng tô vàng ứng với lời giải thích tô vàng bên phải.

from flask import Flask, request, jsonify, render_template app = Flask(__name__)saved_name = "" @app.route("/")def home():    return render_template("index.html") @app.route("/send", methods=["POST"])def send():    global saved_name    data = request.get_json()    saved_name = data["name"]    return jsonify({"status": "ok"}) @app.route("/get")def get_data():    return jsonify({"name": saved_name}) app.run(debug=True)
  • Dòng 1: Nhập 4 công cụ: Flask (tạo server), request (đọc dữ liệu nhận), jsonify (trả JSON), render_template (trả HTML).
  • Dòng 3: Tạo server tên app. __name__ giúp Flask tìm thư mục templates.
  • Dòng 4: Biến saved_name giữ tên đã nhận, ban đầu rỗng, nằm trong bộ nhớ server.
  • Dòng 6–8: Route “/” (trang chủ): mở 127.0.0.1:5000 thì server trả file index.html.
  • Dòng 10–11: Route /send chỉ nhận POST; hàm send() chạy khi có Request đến.
  • Dòng 12: global cho phép hàm sửa biến ngoài hàm. Thiếu dòng này, Python tạo một biến mới trong hàm.
  • Dòng 13–14: Đọc JSON ở Body thành dict {"name": "Lan"}, rồi lưu giá trị của khóa "name".
  • Dòng 15: Trả Response JSON {"status": "ok"} báo đã nhận xong.
  • Dòng 17–19: Route /get (mặc định GET) trả tên đã lưu, ví dụ {"name": "Lan"}.
  • Dòng 21: Bật server. debug=True tự tải lại khi em sửa và lưu code.
